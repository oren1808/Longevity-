# דף שלב א' (פיילוט)

דף סטטי אחד לפי `docs/phase-a-runbook.md` §1.2: נחיתה ← לפני שמתחילים (T2, "מה הביא אותך", למי זה לא מתאים, הסכמה) ← 13 שאלות ← לפני החשיפה ← חשיפה (`full` / `gain-only` / `maintenance`, להסתיר, "מה המספר לא יודע", "מה אם", אמון 1–5) ← "איך חישבנו?" ← 3 פעולות ← משבצת זמן ← וואטסאפ עם קוד P ← הזמנה.

- **המנוע רץ בדפדפן** (`packages/engine`). התשובות קיימות רק בזיכרון של הדף ונמחקות בסגירה או ב"התחלה חדשה". ב־localStorage נשמרים רק `id6` אקראי וקבוצת H/G.
- **אין קריאות רשת חיצוניות** (הגופן Rubik נארז מקומית). אנליטיקס כבוי (`src/config.ts`); כשמדליקים – רק אירועי משפך מה־allowlist ב־`src/track.ts`, בלי תשובות.
- **קוד P:** `{id6}-{action}-{variant}-{cohort}-{h}-{dg}` ועוד `-{gain_bucket}` (a–e) רק כש־`dg = F`. variant: `f` מלאה / `e` קלה / `a` נגישה.
- **כל הערכים זמניים** (באנר קבוע + `isPlaceholder`). ממלאים לפני היציאה את `src/config.ts` (שם מוצר, מפעיל, מייל, תאריך מחיקה, יועץ, מספר וואטסאפ).

npm install

npm run build        # apps/pilot/dist – להעלות לכל אחסון סטטי
