## 2. מיפוי תשובות לרמות

- **"קשה לדעת" / "אין לי איך למדוד":** ה־HR הממוצע המשוקלל לפי שכיחות, לפי המין והגיל של המשתמש. מוסיף +1 לחצי הרוחב (פרק 5).
- **פעילות/כושר:** גורם אחד, שערכו הגרוע מבין רמת הפעילות (שאלה 1) ורמת הכושר (שאלה 2). אם הכושר "קשה לדעת" (כולל "לא עולים מדרגות מסיבה אחרת"), **הפעילות לבדה קובעת**.
- **משקל:** יחס מותניים לגובה אם נמסר, אחרת BMI. אם BMI < 18.5, לוקחים `max(HR_BMI, HR_waist)`. גבולות: הגבול התחתון כלול בטווח (`0.5 ≤ x < 0.6`, `25 ≤ BMI < 30`).
- **ציון תזונה:** 5א + 5ב + 6, בטווח 0–9. 0–3 נמוך, 4–6 בינוני, 7–9 גבוה.
- **חברתי:** לפי הכלל בנספח א' באפיון.
- **עישון 4ב** (נרגילה / סיגריה אלקטרונית / טבק מחומם): שימוש יומי → רמה "פחות מ־10 ביום", אלא אם שאלה 4 כבר נותנת רמה גרועה יותר. "לפעמים" → "הפסיק 5–15" `[advisor]`.

## 3. חישוב ה־HR לכל גיל עתידי x

לכל גיל `x ≥ a` (a = הגיל הנוכחי, בשנים שלמות):

```
w_s(x) = 1                     אם x ≤ 80;  ליניארי ל־0.7 בגיל 90;  0.7 מעל 90
w_o(x) = 1                     אם x ≤ 60;  ליניארי ל־0.5 בגיל 90;  0.5 מעל 90

H_s(x) = 1 + (HR_smk(x) − 1) · w_s(x)                 (עישון, k=1)
H_a(x) = 1 + (HR_alc   − 1) · w_o(x)                  (אלכוהול, k=1)
S      = 0.75 · Σ_{i∈cluster} ln HR_i                  (פעילות/כושר, כוח, תזונה, משקל, שינה, סדירות, חברתי)
H_c(x) = 1 + (exp(L · tanh(S / L)) − 1) · w_o(x),     L = ln 3
H(x)   = H_s(x) · H_a(x) · H_c(x)
```

- **ההחלשה עם הגיל מוחלת על האשכול אחרי התקרה**, לא על כל גורם בנפרד.
- **C מוחל רק כמחלק אחרון** (פרק 4). לא בתוך tanh ולא בתוך ההחלשה.

### 3.1 עישון לפי זמן מגמילה וגיל הגמילה

```
HR_smk(x) למעשן נוכחי = HR_current (2.0 / 2.5 / 3.0 לפי כמות)
לגמול (t = שנים מאז הגמילה ב־x, Q = הגיל בגמילה):
  HR_tier(t) = 1.70 אם t < 5;  1.30 אם 5 ≤ t < 15;  1.10 אם t ≥ 15     (מדרגות בשנים שלמות)
  HR_smk(x)  = HR_tier(t) + ρ(Q) · (HR_ref − 1)
  ρ(Q) = 0 (Q<35) / 0.1 (35–44) / 0.3 (45–54) / 0.5 (55+)              [advisor]
```

- **גמול לפי תשובה:** "הפסיק לפני פחות מ־5 שנים" → t₀ = 2.5. "5–15" → t₀ = 10. "יותר מ־15" → t₀ = 20. `Q = a − t₀`. `HR_ref = 2.5` (רמת "10–19", כי עוצמת העישון לפני הגמילה לא ידועה) `[advisor]`.
- **פעולת גמילה:** t = 0 בגיל a, Q = a, `HR_ref = HR_current`.
- **למה:** בלי ρ, גמילה בגיל 45 שווה כ־9 שנים במקום 5–6.5, כי הסיכון יורד ל־1.10 אחרי 15 שנה בלי קשר לגיל הגמילה (Jha: כ־10 / 9 / 6 / 4 שנים בגמילה בגילאי 30 / 40 / 50 / 60).

## 4. נרמול ותוחלת

```
q'_x = 1 − (1 − q_x)^( H(x) / C[sex][a] )
e_a  = 0.5 + Σ_{k=1}^{110−a} Π_{j=0}^{k−1} (1 − q'_{a+j})        (k מתחיל ב־1)
point = a + e_a
```

- **`C[sex][a]`** = השורש של `mean_pop[ e_a(answers; C) ] = e_a(CBS)`. הממוצע מחושב על דגימת מונטה קרלו עם seed קבוע, `N ≥ 20,000`, לפי השכיחות בגיל a.
  - **לא** מגדירים את C כממוצע של H. זה מטה את התוצאה בכ־+1 שנה.
  - **לכל גיל בודד**, לא לפי קבוצות גיל. אחרת יום הולדת מוריד את ההערכה.
  - **C אינו עולה עם הגיל:** אחרי החישוב מוחלת החלקה מונוטונית (isotonic), כדי שיום הולדת לעולם לא יוריד את הנקודה.
- **C נשאר קבוע לכל משתמש** בכל ההרצות: נקודה, CI, פעולות, פוטנציאל, ו"מה אם".

## 5. טווח

```
spread = e(כל ה־HR בגבול CI התחתון) − e(כל ה־HR בגבול CI העליון)        (בשנים, C קבוע)
hw     = clamp(round_half_up(0.06 · e_rem + 0.5 · spread), 2, 4)
mods   = min(1, [מין X] + [≥1 "קשה לדעת"] + [גיל 18–24] + [שער = "מעדיפים לא לענות"])
hw     = hw + mods                                                       (מקסימום 5)
low    = round(point) − hw;   high = round(point) + hw
```

- **רוחב הטווח תמיד זוגי.** בדוגמאות בממשק: "בין 82 ל־88", לא "82 עד 87".
- **רוחב צפוי** (גבר טיפוסי, ערכים זמניים): ±4 בגיל 30, ±3–4 בגיל 45, ±3 בגיל 60.

## 6. פעולות, פוטנציאל ומנוף

**יעדי הפעולות** (המקור המלא: `docs/actions.md`):

| פעולה | יעד | adherence | ראיות |
|---|---|---|---|
| פעילות (`walk30`) | 150–299, וגם הכושר עולה רמה אחת | 5/7 | B |
| כוח (`strength2`) | 2+ | 2/7 | C |
| גמילה (`smk_quit_date`) | "הפסיק עכשיו" (פרק 3.1) | – | A |
| תזונה | רמה אחת למעלה | 5/7 | C |
| שינה (`bedtime`) | 7–8 שעות (לא ממשתמשים שישנים 9+) | 5/7 | C |
| סדירות (`wake_same`) | סדיר | 6/7 | C |
| אלכוהול | רמה אחת למטה, לא מתחת ל־0–7 | 4/7 | B |

- **`gainYears`** = `point(יעד) − point(נוכחי)`, כש־C קבוע.
- **`gainYears.low/high`** = אותו חישוב כשכל ה־HR בגבול CI העליון / התחתון.
- **`potentialGain`** = כל הפעולות ביעד **יחד**. **לא כולל משקל וגורם חברתי.**
- **דירוג:** `gainYears × weight(grade)`, כש־A=1.0, B=0.8, C=0.6. פעולות בלי שנים מדורגות אחרונות.
- **`biggestLever`** = הפעולה הראשונה בדירוג. **אם זו פעולת עישון**, `biggestLever.kind = 'smoking'` והממשק מציג נוסח ניטרלי (ראו האפיון, 6.1).

## 7. שעות ליום שבוצע

```
hoursPerDay = clamp( roundToQuarter( gainYears · 8766 / (365.25 · e_rem,target · adherence) ), 0.25, 3 )
```

- **עישון:** אין `hoursPerDay`. הזיכוי ניתן רק דרך רמות העישון (פרק 8).
- **פעולות בלי שנים:** `hoursPerDay = null`, והממשק סופר ימים במקום שעות.
- **שעות בשבוע** = `min(daysDone, doseDays) × hoursPerDay`.

## 8. זיכוי (`creditedGain`)

```
weeksFull = מספר השבועות הרצופים במינון המלא (שבוע נחשב = daysDone ≥ weekCountThreshold)
credit = 0                     אם weeksFull < 12
       = 0.5 · gainYears       אם 12 ≤ weeksFull < 26
       = 1.0 · gainYears       אם weeksFull ≥ 26 וכל בדיקה חודשית אישרה; אחרת 0.5
```

- **עישון:** תזמון זהה, לפי שבועות בלי עישון. שווי הזיכוי = הרווח לפי מסלול הרמות מתאריך הגמילה × 0 / 0.5 / 1.
- **הפסקה בהרגל:** ראו את האפיון, 4.6. במשך 4 שבועות הזיכוי מוקפא, ואחר כך חוזר בעדינות בבדיקה הבאה.
- **ב־v0** הזיכוי קיים במנוע ובטסטים בלבד. הממשק שלו נדחה (רוב משתמשי הפיילוט לא יגיעו ל־12 שבועות).

## 9. תצוגה

| תנאי (לפי סדר העדיפות) | `display` |
|---|---|
| גיל ≥ 75, או שער = "כן" | `gain-only` |
| `potentialGain.high < 0.5` | `maintenance` |
| אחרת | `full` |

- שער = "מעדיפים לא לענות" → `full`, עם +1 לחצי הרוחב.
- **ב־75+** הפעולות עדיין מדורגות לפי רווח. פעולות בלי שנים (איזון, חברתי) מופיעות אחריהן.

## 10. "מה אם"

- **פלט:** `{ point, potentialGain }`. בממשק מוצג "בממוצע בין X ל־Y" (טווח, לא "עד").
- **מוסתר:** במצבי `gain-only`, `maintenance`, ו"להסתיר את המספר".

## 12. טסטים מבניים (חובה)

- **מונוטוניות:** הסדר נקבע לפי HR. "שיפור" = ירידה ב־HR (למשל 9+ שעות שינה גרוע מ־7–8).
- `low ≤ high`; `potentialGain ≥ 0`; `potentialGain ≥ max(gainYears)`.
- **מגן עישון:** מעשן קופסה עם 4 גורמים גרועים מקבל רווח גמילה ≥ 4 בכל גיל 25–74.
- **חצי רוחב** בין 2 ל־5. הרוחב זוגי.
- **`hoursPerDay`** בין 0.25 ל־3, או null.
- **יום הולדת:** `point(a+1) ≥ point(a) − 0.05` לכל פרסונה וכל גיל 18–99.
- **`display`** לפי פרק 9.
- **`creditedGain`:** 0 / 50% / 100% לפי פרק 8, כולל עישון.
- **placeholder:** כל ערך `status: "placeholder"` → `isPlaceholder = true`.
- **דטרמיניזם;** צילומי מצב לפרסונות לכל גרסת `factors`.
